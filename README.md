# 点击index.html即可开始游戏

## 【一、基本胜负】
1. 游戏采用“五局三胜制”。
2. 每一局双方正常轮流落子。
3. 任意一方形成连续五子，该局立即结束，该方获得 1 分。
4. 一方累计获得 3 分后，整场游戏结束，该方获胜。
5. 如果当前棋盘已经没有可用位置，则该局判为和棋，不增加任何一方的分数。


## 【二、棋盘不会在每局结束后清空】
这是本游戏最核心的规则。
每一局结束后，棋盘上的普通棋子全部保留，进入下一局继续使用。
因此，下一局是在上一局的棋盘局面基础上继续进行，而不是重新开始一个空棋盘。

## 【三、胜利五子移除】
当某一方通过连续五子获胜后：
1. 找出本次形成胜利条件的五个棋子。
2. 将这五个棋子从棋盘上移除，恢复为空位。
3. 棋盘上的其他棋子全部保留。
如果存在六连或更长的连续棋子，则全部移除。

## 【四、冻结机制】
为了避免下一局直接利用上一局已经形成的棋形继续鏖战，需要加入“冻结区域”。

上一局结束后：
1. 获取上一局结束时棋盘上所有仍然存在的棋子。
2. 每一个这样的棋子，其自身所在位置以及周围八个位置（即以该棋子为中心的 3×3 区域）全部标记为“冻结区域”。
3. 冻结区域在下一局开始时暂时不能落子。
4. 注意：已经因为获胜而被移除的五个棋子不再存在，因此它们的位置不产生冻结区域。
5. 冻结区域只根据“上一局结束时的棋盘状态”生成，不会因为新一局产生的新棋子而继续扩大。

例如上一局结束后某个棋子位于 (x,y)，那么：

(x-1,y-1) ~ (x+1,y+1)

这 3×3 范围属于冻结区域。

多个棋子的冻结区域可以重叠，最终取并集。

## 【五、冻结解除】
新的一局开始后，双方不能在冻结区域内落子。

新一局需要先进行 随机5-15 步后才可以正常落子：

之后棋盘恢复正常，双方可以在原来的棋子附近自由落子。

特别注意：
1. 新一局前三步产生的新棋子不会产生新的冻结区域。
2. 冻结区域不会动态扩大。
3. 冻结结束后一次性解除本轮全部冻结区域。

## 【六、核心游戏逻辑】
因此完整流程是：

第一局：
正常五子棋 → 一方五连 → 获胜方 +1分 → 移除获胜的五个棋子 → 根据剩余棋子生成冻结区域。

第二局：
继承上一局棋盘 → 冻结区域暂时不能落子 → 双方完成3步 → 解除冻结 → 继续正常下棋 → 一方五连 → 再次处理胜利五子和冻结区域。

如此循环。

任意一方先获得3分，整场游戏结束。

## 【七、设计目的】
这个机制的核心目的不是简单地连续玩五局，而是让棋盘状态跨局保留。

上一局留下的棋子相当于“历史棋形”。
下一局开始时，这些棋子及其周围区域暂时被冻结，迫使双方先在外围发展。
经过3步后冻结解除，双方可以让新一局形成的棋形与上一局留下的棋形产生联动。

因此玩家需要同时考虑：
1. 当前这一局能否获胜；
2. 获胜后自己的五个棋子被移除会造成什么影响；
3. 下一局开始时哪些区域会被冻结；
4. 前三步应该在哪里建立新的棋形；
5. 三步后冻结解除时，新旧棋形如何连接。
